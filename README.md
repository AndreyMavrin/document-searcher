# Тестовое задание Python

Необходимо написать очень простой поисковик по текстам документов. Данные хранятся в БД по желанию, поисковый индекс в эластике.

Ссылка на тестовый массива данных: [csv]

**Структура БД:**

- `id` - уникальный для каждого документа;
- `rubrics` - массив рубрик;
- `text` - текст документа;
- `created_date` - дата создания документа.

**Структура Индекса:**

- `id` - id из базы;
- `text` - текст из структуры БД.

**Необходимые методы**

- сервис должен принимать на вход произвольный текстовый запрос, искать по тексту документа в индексе и возвращать первые 20 документов со всем полями БД, упорядоченные по дате создания;
- удалять документ из БД и индекса по полю `id`.

**Технические требования:**

- любой python фреймворк кроме Django и DRF;
- `README` с гайдом по поднятию;
- `docs.json` - документация к сервису в формате openapi.

**Программа максимум:**

- функциональные тесты;
- сервис работает в Docker;
- асинхронные вызовы.


## Быстрый запуск

### 1. Настройка окружения
Скопировать шаблон переменных окружения в реальный конфигурационный файл:
```
cp .env.example .env
```
Прописать в `.env` свои параметры.

### 2. Запуск сервиса
```
docker compose up --build -d
```
## Документация API

**Swagger UI:** автоматически разворачивается и доступно по адресу: [http://localhost:8080/docs](http://localhost:8080/docs)

### Реализованные эндпоинты:
- `GET /api/documents/search?query=текст` — Полнотекстовый поиск по индексу. Возвращает первые 20 документов со всеми полями БД, упорядоченные по дате создания (от свежих к старым).
- `DELETE /api/documents/{id}` — Каскадное удаление документа по его уникальному `id` из реляционной базы данных и инвертированного поискового индекса одновременно.
